        Lock

        A content lock hides a notebook, folder or note behind a password and keeps it out of the app until the password is entered. It is not encryption: the note stays plaintext on disk, in git and in backups, so anyone with server access can still read it.

        This notebookOpen a notebook to lock it.

        Folders and notes have their own lock entries: use a folder's or note's ⋯ menu in the sidebar.

        Templates

        Create note templates with variables like {{title}}, {{date}}, {{time}}, {{id}}, {{path}}, {{folder}}. Use New note from template… in the + menu or a folder's ⋯ menu.

        About

        noteroot stores notes as plain Markdown files on your server. Preferences on this page are saved in this browser only. Build version: —

        Vim mode runs real Vim (WASM) in the page. Mobile devices always use the plain-text editor.

        Edit vimrc

        Vim commands run each time Vim starts in the editor, after the built-in settings, for example set number or set tabstop=4. Saved in this browser. Lines starting with " are comments.
